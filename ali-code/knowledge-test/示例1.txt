Python 编程规范（节选）
命名规范：

变量名和函数名使用小写字母加下划线，如 user_name、get_user_info。

类名使用大驼峰命名法，如 UserManager、DatabaseConnection。

常量使用全大写加下划线，如 MAX_RETRY_COUNT、DEFAULT_TIMEOUT。

私有变量和私有方法以单下划线开头，如 _internal_cache。

代码示例：读取配置文件

python
import configparser

def load_config(config_path: str) -> dict:
    """读取 INI 配置文件并返回字典。"""
    config = configparser.ConfigParser()
    config.read(config_path, encoding="utf-8")
    
    result = {}
    for section in config.sections():
        result[section] = dict(config[section])
    return result

if __name__ == "__main__":
    cfg = load_config("app.ini")
    print(cfg.get("database", {}).get("host"))
异常处理原则：

不要使用裸 except:，要捕获具体异常类型。

捕获异常后要记录日志，不要静默吞掉。

自定义异常应继承自 Exception 或其子类。

使用 finally 确保资源释放，或使用 with 语句管理上下文。

文档 ：RAG 系统架构说明
什么是 RAG：
RAG（Retrieval-Augmented Generation，检索增强生成）是一种将信息检索与大语言模型生成相结合的技术架构。它先从知识库中检索出与问题相关的文档片段，再把这些片段作为上下文交给大语言模型，让模型基于真实资料生成回答，从而减少幻觉、提高准确性。

RAG 的典型流程：

文档加载：从 PDF、Word、网页、数据库等来源读取原始文档。

文档分块：将长文档切分成适当大小的片段（chunk），常见大小 256-1024 token。

向量化：使用嵌入模型（如 text-embedding-3-small、bge-large-zh）把每个片段转成向量。

存储：将向量和原文存入向量数据库，如 Milvus、Qdrant、pgvector、Redis。

检索：用户提问时，把问题也向量化，在向量库中做相似度搜索，召回 Top-K 片段。

重排序：可选，用 rerank 模型对召回结果精排，提高相关性。

生成：把召回片段和问题一起拼成 Prompt，交给 LLM 生成最终答案。

常用向量数据库对比：

数据库	类型	优势	适用场景
Milvus	专用向量库	分布式、十亿级扩展	大规模生产环境
Qdrant	专用向量库	性能强、过滤好、部署简单	中小规模生产
pgvector	PostgreSQL 扩展	与业务数据同库、SQL 友好	已有 PG 技术栈
Redis	内存数据库	延迟极低、可兼做缓存	实时性要求高
Pinecone	全托管服务	免运维、开箱即用	快速验证、无运维团队
分块策略建议：

固定长度分块：简单，但可能切断语义。

按段落分块：保留语义完整性，适合结构化文档。

递归分块：按标题层级递归切分，兼顾语义和长度。

重叠分块：相邻块之间保留 10%-20% 重叠，避免边界信息丢失。

员工入职指南
入职第一天流程：

到前台领取工牌和办公用品。

联系 IT 部门开通邮箱、内网账号、VPN。

加入部门企业微信群，修改群昵称为“姓名-岗位”。

阅读《员工手册》，签署保密协议。

与直属上级进行 30 分钟的一对一沟通，明确试用期目标。

试用期规定：

试用期一般为 3 个月，特殊岗位可延长至 6 个月。

试用期薪资为转正薪资的 80%。

试用期考核通过后办理转正手续，考核不通过可延长一次或解除合同。

福利待遇：

五险一金：按国家规定缴纳。

补充医疗：转正后享受商业补充医疗保险。

带薪年假：入职满一年后享受 5 天年假，每满一年增加 1 天，上限 15 天。

弹性工作：标准版及以上版本支持弹性上下班，核心工作时间 10:00-16:00。

报销流程：

保留发票和消费凭证。

在企业微信“报销”应用中填写报销单。

上传发票照片，选择费用类型和归属项目。

提交后由直属上级审批，财务复核。

审批通过后 5 个工作日内打款到工资卡。

文档 7：常见问题 FAQ
Q1：如何重置密码？
A：访问登录页，点击“忘记密码”，输入注册邮箱，系统会发送重置链接，链接 30 分钟内有效。

Q2：支持哪些浏览器？
A：推荐使用 Chrome 90+、Edge 90+、Firefox 88+、Safari 14+。不支持 IE 浏览器。

Q3：数据会丢失吗？
A：平台每天凌晨 2 点自动备份，备份保留 30 天。免费版不提供数据导出，标准版及以上支持导出为 CSV 和 JSON。

Q4：可以多人同时编辑一个文档吗？
A：可以。文档协作模块支持多人实时编辑，光标位置实时同步，冲突自动合并。
